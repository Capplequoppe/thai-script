# 7c99d3a99022 — Task 5.2 — backfill word_class with per-entry provenance

This commit implements word_class backfill for 3,161 missing vocabulary entries using a rule-and-lexicon classifier, with 39 refusals kept labeled with their source. The author selected rules through evidence-based cross-validation on buckets 1–9: dropped suffix rules underperforming the lexicon (al, ic, ary, ive, able, ish, tion, ment, ation, ism), kept those winning decisively (ate, ful, ness, ous, ise), and tuned the modal rule from "mod" to "aux". Closed-class rules were retained because they substantially outperformed the plain lexicon (prep 0.75 vs 0.06). A committed baseline test catches future classifier regressions. The author initially questioned dropping -tion/-ment/-ation on linguistic grounds but confirmed the data showed ties, justifying removal. Held-out accuracy improved 0.756→0.764; balanced accuracy jumped 0.469→0.558.
