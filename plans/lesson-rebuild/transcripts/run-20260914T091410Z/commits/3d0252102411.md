# 3d0252102411 — Add the deck slide type to LessonIntro, dispatched on LessonContent

Adds a dispatch pattern to `LessonIntro` that renders a `DeckSlide` component when lesson content resolves to a deck type, alongside existing video support. The implementation resolves lesson content in `LessonPage` and `CatchUpPage` before rendering, passing the content through to `LessonIntro` which gates slide type on its presence. Audio replay resets per-slide rather than per-URL (matching `Flashcard`'s `useResetOnCardChange` pattern) since the deck schema lacks an audio field. An `isUnauthoredEmptyDeck` helper handles the zero-slide case before validation, and a `suppressVideo` prop lets `CatchUpPage` skip video slides even when content resolves to "video" (preserving the existing behavior that already-watched lessons don't replay). Test stubs must be registered before render to avoid cross-test contamination; red-proof mutations on audio dependency array and completion callback confirm AC5 and AC6 assertions catch their respective bugs.
