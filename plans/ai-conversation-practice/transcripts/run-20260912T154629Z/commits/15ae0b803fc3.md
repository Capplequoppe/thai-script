# 15ae0b803fc3 — fix(e2e): block service workers in the conversation-practice project

Blocks service worker registration in the conversation-practice e2e tests using Playwright's `serviceWorkers: 'block'` context option to prevent mid-test page reloads. The agent discovered that the app's PWA service worker registration was failing in dev mode (fetching `/thai-script/sw.js` returned HTML instead of the worker script due to Vite's dev server MIME type mismatch), causing unexpected full page reloads during the recording flow. This destabilized tests by interrupting the recording state mid-gesture. The fix is test-only and scoped to the conversation-practice project, preserving production service worker functionality while eliminating the flakiness without modifying app code. Tests passed consistently after this change.
