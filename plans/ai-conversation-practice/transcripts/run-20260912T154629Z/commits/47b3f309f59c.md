# 47b3f309f59c — feat(conversation): pick the opening question from the bank by known vocabulary

Implements vocabulary-aware opening-question selection: replaces a hardcoded question with a pick from a pre-generated conversation-starter bank, scoped to each learner's known vocabulary. The `select_entry()` function filters entries to those whose words are a subset of known vocabulary, prefers the hardest qualifying tier, and uses SHA256-based tie-breaking among same-tier entries; falls back to the simplest tier if nothing qualifies. Each criterion was verified via mutation testing (red proofs) and end-to-end testing with real backend and learner vocabularies. Pre-existing recording tests confirmed green after the change. The agent incidentally edited `conversation-practice-fail.spec.ts` (outside stated covers) to accommodate the removed hardcoded question; this scope mismatch stems from a prior task's spec split not being reflected in the covers list.
