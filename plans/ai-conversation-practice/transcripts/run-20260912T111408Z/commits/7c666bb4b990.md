# 7c666bb4b990 — Add offline generator and curated conversation-starter bank

Adds an offline conversation-starter bank generator (Qwen2.5-7B-Instruct per vocabulary tier) and ~40-entry curated JSON bank. The designer chose tier-wise generation to match frontend contracts, splitting detection: algorithmic filtering for vocab compliance (newmm + allowed-word-set) but human review for broader quality (phrasing, appropriateness). Content-hash IDs ensure stability across re-runs; this was verified through red tests showing order-derived IDs would mutate. Cross-tier deduplication was fixed mid-generation when duplicates ate per-tier floors—the loop now excludes already-claimed Thai texts. Quality gates added for machine-detectable defects (mixed politeness particles, non-questions) but not outliers. The plans/ directory was missing from this worktree, blocking the observe-red macro, so tests were run individually with `-k` selectors instead.
