# e4b668af011c — Implement the backend conversation pipeline: STT, judge, TTS wired to the contract

Wires STT (faster-whisper), judge (Qwen2.5-7B), and TTS models into the API contract, loading once at startup and replacing task 1.1's 501 placeholders with live pipeline endpoints. 

The judge prompt required iterative refinement: initial few-shot examples degraded performance, so the team debugged with fixed transcripts, discovering that inline English text was corrupting Thai markers mid-token. They also hardened the "don't know" rule with MUST-level language and locked TTS to seed=42 for deterministic synthesis. Text-to-speech artifacts initially triggered false negatives; simplified phrasing fixed this. Ruff 0.16.7's defaults flag broad exception catches, which remain intentional per AC5's design (any model layer error maps to "unscored"), so suppressions use justified comments. All nine acceptance criteria confirmed via red/green testing; deterministic judge verdicts match the spike's hand-verified judgments.
