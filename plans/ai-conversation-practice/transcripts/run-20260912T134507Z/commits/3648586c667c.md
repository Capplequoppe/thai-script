# 3648586c667c — Warm up STT/judge/TTS models at startup, not on the first real request

This commit adds warm-up inference calls for Whisper, judge LLM, and TTS models during backend startup to eliminate cold-start overhead on the first real request.

The e2e test was flaking reproducibly: whichever spec ran first after backend launch would time out, suggesting the initial inference call hit significant CUDA kernel autotuning or JIT compilation delays. Rather than letting the first user request pay this penalty, warm-up dummy calls (minimal silent WAV for STT, sample text for judge/TTS) now execute during `load_models_into`, ensuring subsequent real requests have warm latencies from the start. The fix is scoped to backend startup only and resolved the repeated test timeouts.
